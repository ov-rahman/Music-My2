# Ноты для вставки — бразильский фонк для GarageBand

Одностраничный сайт: готовая петля бразильского фонка, показанная как пиано-роллы —
шесть дорожек, четыре такта, каждая нота на своём месте. Смотришь на сетку и повторяешь
в GarageBand, либо скачиваешь MIDI и перетаскиваешь в проект.

## Что на странице

- **Шесть пиано-роллов**: кик, 808 бас, аккорды, лид, плак, перкуссия. Названия нот слева,
  такты и доли сверху, ширина блока = длина ноты.
- **Экспорт MIDI** — весь набор одним файлом или каждая дорожка отдельно.
  Формат 1, 96 тиков на четверть, ударные на 10-м канале по стандарту GM.
- **Воспроизведение** — вся петля синтезируется через Web Audio, семплы не нужны.
  Плейхед идёт по всем роллам разом.
- **Инструменты GarageBand** для каждой дорожки, порядок вставки, схема сведения.

Параметры: 130 BPM · A minor · 4/4 · сетка 1/16 · Am → F → G → Em.

Кик стоит группами 3-3-4-3-3 — позиции 1.1, 1.4, 2.3, 3.3, 4.2 в каждом такте.
Это и делает бит бразильским.

## Запуск

Открыть `index.html` в браузере. Внешних зависимостей нет — один файл.

Управление: `Пробел` — старт/стоп, кнопки «Такт 1–4» — переход по петле,
«Крупнее» — увеличить сетку на телефоне.

## Ограничение

Импорт MIDI работает только в GarageBand на Mac. На iOS его нет —
там ноты вбиваются по схеме вручную.
