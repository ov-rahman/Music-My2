# Куда вставлять бит

Одностраничный сайт-шпаргалка: готовый паттерн **бразильского фонка с 8-битными синтами**
и инструкция, куда что ставить в GarageBand.

На странице:

- **Живой шаговый секвенсор** — 6 дорожек × 16 шагов, звук синтезируется через Web Audio
  (семплы не нужны). Клетки кликабельны, есть пресеты частей: интро / бит / дроп / брейк.
- **Позиции каждой ноты** по долям в формате `доля.шестнадцатая` и названия конкретных
  инструментов GarageBand для каждой дорожки.
- **Полная раскладка нот** на 4 такта для ввода в пиано-ролл.
- **Структура трека** на 64 такта.
- **Стартовые значения для сведения** — громкости, панорамы, реверб, EQ.

Параметры: 130 BPM · F# minor · 4/4 · сетка 1/16 · прогрессия F#m → D → E → C#m.

## Запуск

Открыть `index.html` в браузере. Внешних зависимостей нет — один файл.

Управление: `Пробел` — старт/стоп, клик по клетке — включить шаг,
клик по названию дорожки — заглушить её.
